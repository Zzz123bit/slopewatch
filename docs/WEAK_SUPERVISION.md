# 自监督（规则）标注与公开数据集

> 目标：不靠人工逐张涂抹，也能得到可训练的语义标签；同时引入公开标注数据做对比与预训练。
> 适用版本：v1.0 · 2026-11-28

## 一、为什么能“自监督”

这套项目的特殊之处在于：**两期照片会先被重建成三维、算出高程差（DoD），再反过来给二维照片打标签**。
冲沟、坍塌这些类别本身就是“地表形态变化”，而 DoD 是直接测出来的几何量，比从阴影/纹理去猜可靠得多。
地貌学里对“冲沟/坍塌”的判定本来就有可计算的形态标准，把它们写成规则即可自动出标签。

```
两期照片 → VGGT 重建 → 配准 → DoD → 形态规则 → 三维标签栅格 → 投影回各视角 → 二维掩膜 → 训练分割模型
```

这条链路已经实现在：

| 步骤 | 代码 |
|---|---|
| 形态规则 | `slopewatch/weak_labels.py` |
| 规则接入任务 | `slopewatch/jobs.py`（产出 `weak_labels.png` / `weak_labels.json`） |
| 规则投影回照片并生成训练集 | `scripts/self_train_segmentation.py` |
| 微调 | `scripts/finetune_segmentation.py` |

## 二、结构标准与可计算判据

规则默认参数集中在 `slopewatch/weak_labels.py` 的 `DEFAULT_RULES`，来源是土壤侵蚀分类与地貌学通行定义：

| 判据 | 默认阈值 | 依据（工程化解释） |
|---|---|---|
| 变化起点 | 深度 ≥ 5 mm | 低于重建噪声的变化不参与分类 |
| 冲沟：长度 | ≥ 100 mm | 细沟/冲沟的长度下限，短于此更像局部斑块 |
| 冲沟：宽度 | ≤ 400 mm | 过宽则更可能是片蚀或塌陷 |
| 冲沟：长宽比 | ≥ 3 | 线状下切是冲沟的核心形态特征 |
| 坍塌：面积 | ≥ 400 mm² | 排除零星噪点 |
| 坍塌：最大深度 | ≥ 10 mm | 需要明显的垂向落差 |
| 坍塌：长宽比 | < 2.5 | 紧凑斑块，而非条带 |
| 坍塌：邻近堆积 | 40 mm 内 | 崩塌通常伴随坡脚堆积 |

参考口径：SL 190-2007《土壤侵蚀分类分级标准》、GB/T 20465-2006《水土保持术语》，
以及 USDA-NRCS 对 rill / gully 的经典定义（沟深/沟宽 30 cm 量级）。
注意：本项目的重建分辨率不足以稳定区分“细沟 vs 冲沟”，因此合并为一个“冲沟”类；
阈值是**默认值**，现场应按相机距离、重建精度重新标定。

## 三、能自动标什么、不能标什么

| 类别 | 能否规则自动标注 | 说明 |
|---|---|---|
| 冲沟（1） | ✅ 可以 | 线状、下切，DoD 形态稳定 |
| 坍塌（2） | ⚠️ 部分可以 | 需要邻近堆积或陡壁判据，漏检率较高，建议人工复核 |
| 其他（0） | ✅ 可以 | 有效区内未达阈值的部分 |
| 防护（3） | ❌ 不行 | 防护垫是“材料”而非“形变”，需要颜色/纹理识别或人工 |
| 对照（4） | ❌ 不行 | 对照区是试验设计信息，不在影像几何里 |
| 未标注（255） | ✅ 自动 | 无效区、投影未覆盖区、规则不确定区 |

结论：**几何类（冲沟/坍塌）可以自监督，材料类（防护/对照）仍要人工或额外的材料分类器**。
实操上建议“规则先出 70%，人工只改 30%”，比全手工快一个数量级。

## 四、实测（合成场景，仅验证链路）

在 `data/samples/synthetic_sem`（雨前/雨后各 8 张）上运行：

```powershell
python scripts/self_train_segmentation.py --scene data/samples/synthetic_sem `
  --out data/self_supervised/sem --max-views 4 --finetune-epochs 2
```

结果：

| 指标 | 数值 |
|---|---|
| 有效格网 | 82,065 |
| 侵蚀格 | 15,723 |
| 规则判为冲沟 | 14,304（占侵蚀 91%） |
| 规则判为坍塌 | 0（该场景坍塌未满足“邻近堆积”判据） |
| 区域数 | 177 |
| 投影到 4 个视角 | 未标注比例 26%–54% |
| 2 轮微调 mIoU | 0.067（3 张训练图，仅证明流程可跑，不代表精度） |

解读：规则标签本身合理；但**一个场景只有 4 张图，远不足以训练**。要得到可用模型，
需要 20–50 个场景、上百张自监督图，再配合少量人工修正。

## 五、公开标注数据集（已下载）

网络可访问 Zenodo，已下载三个 CC-BY-4.0 的滑坡分割数据集（卫星瓦片，二分类：滑坡/背景）：

| 数据集 | DOI | 图-掩膜对 | 原始格式 |
|---|---|---|---|
| Nepal landslide dataset | 10.5281/zenodo.3688363 | 230 | GeoTIFF + PNG |
| Italy landslide dataset | 10.5281/zenodo.4287425 | 104 | GeoTIFF + PNG |
| Japan landslide dataset | 10.5281/zenodo.3775870 | 106 | GeoTIFF + PNG |
| **合计** | — | **440 对** | 100×100 ~ 180×160 瓦片 |

整理脚本：`scripts/prepare_external_datasets.py`，输出 `data/external/prepared/<name>/{images,masks}`（PNG，掩膜 0/1）
与 `manifest.json`（含 DOI、许可、数量）。

**用途与边界**：

- 可以作为“滑坡/非滑坡”二分类的**预训练**或外部评测，验证分割骨干是否正常；
- **不能**直接当成本项目的 5 类标签：它只有“滑坡/背景”，没有冲沟、防护垫、对照区；
- 卫星俯视图与手机近景差异大，跨域直接迁移效果有限，建议只用于预训练特征。

数据许可：CC-BY-4.0，使用时需在报告中注明来源与 DOI。

## 六、推荐工作流（自监督 + 主动学习）

1. **规则冷启动**：对每个试验场景跑一次照片任务，得到 `weak_labels.png`（自动冲沟/坍塌）；
2. **批量生成训练集**：对 20–50 个场景运行 `self_train_segmentation.py`，得到数百张“图 + 规则掩膜”；
3. **首轮训练**：`finetune_segmentation.py` 在规则掩膜上训练 15–20 轮；
4. **主动学习挑难例**：用模型预测与规则标签不一致、或置信度低的图，交给人工只改这些（预计占总量的 20–30%）；
5. **二轮训练**：规则掩膜 + 人工修正混合训练，重复 2–3 轮；
6. **验收**：留出场景（不参与训练）评估 mIoU 与冲沟/坍塌 IoU。

## 七、风险与合规

| 风险 | 说明 | 对策 |
|---|---|---|
| 规则阈值不适配 | 相机距离、重建精度变化会改变 5 mm / 100 mm 的合理性 | 每个场景先用标尺/已知体校验，再调 `DEFAULT_RULES` |
| 自我强化偏差 | 模型学规则标签，规则错则模型跟着错 | 保留人工抽查；用不一致样本做主动学习 |
| 坍塌漏检 | 邻近堆积判据较严 | 放宽 `deposition_adjacency_mm` 或人工补标 |
| 防护/对照缺失 | 规则无法生成这两类 | 保留人工标注或训练材料分类器 |
| 数据集许可 | CC-BY-4.0 需要署名 | 在报告/论文中列 DOI 与来源 |
| 域差距 | 卫星瓦片 vs 手机近景 | 只用于预训练，不做最终评测 |

## 八、一键命令汇总

```powershell
# 1) 规则标签 + 投影 + 可选微调（单场景）
python scripts/self_train_segmentation.py --scene data/samples/synthetic_sem `
  --out data/self_supervised/sem --max-views 4 --finetune-epochs 15

# 2) 外部数据集整理
python scripts/prepare_external_datasets.py

# 3) 人工修正（只改规则错的地方）
python scripts/annotate.py --images data/self_supervised/sem/images --masks data/self_supervised/sem/masks

# 4) 混合训练（规则 + 人工）
python scripts/finetune_segmentation.py --images data/self_supervised/sem/images `
  --masks data/self_supervised/sem/masks --epochs 20
```
