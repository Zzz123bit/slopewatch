# 真实照片标注与微调指南

目标：用 100–200 张你自己的室内降雨试验照片，把语义分割模型从“合成数据”迁移到“你的坡面”。

## 1. 需要准备什么

- **照片**：100–200 张（最低 40 张也能起步），来自雨前/雨中/雨后不同时相。
- **覆盖度**：不同光照、不同坡段、有/无防护垫、有/无明显冲沟、有/无坍塌。
- **均衡**：冲沟、坍塌、防护、对照四类各至少出现在 15–20 张里；“其他”每张都有。
- 照片里最好有一把标尺或 ArUco 靶标（后期尺度标定用）。

选图时不要全是同一位置，建议按“时相 × 坡段”各挑几张。

## 2. 类别定义

| ID | 类别 | 标注规则 |
|---|---|---|
| 0 | 其他 | 背景、标尺、工具、坡面外区域、没有明显变化的土面 |
| 1 | 冲沟 | 连续下切、宽度 ≥ 2 cm、长度 ≥ 5 cm 的沟槽；只标沟槽本身，不标阴影 |
| 2 | 坍塌 | 局部陡壁、坑、崩落体，长宽比通常 < 3；与冲沟区分不开时标 255 |
| 3 | 防护 | 绿色格栅、土工布、覆盖物等人工防护区域 |
| 4 | 对照 | 同一工况下**没有防护**的裸土区（用于效果对比） |
| 255 | 未标注 | 拿不准的区域；训练时会被忽略 |

原则：**宁可标 255，不要瞎猜**。边界误差 1–2 cm 可以接受，把阴影、水膜、反光标成冲沟会直接教坏模型。

## 3. 标注流程（推荐：模型预标注 + 人工修正）

```powershell
# 1) 用现有模型生成初稿（几十秒）
python scripts/preannotate.py --images data\real_photos --masks data\real_masks

# 2) 打开修正工具，逐张改错
python scripts/annotate.py --images data\real_photos --masks data\real_masks
```

修正工具快捷键：

| 按键 | 作用 |
|---|---|
| `0`–`4` | 选择类别（其他/冲沟/坍塌/防护/对照） |
| `5` | 橡皮（标成 255） |
| `[` `]` | 缩小/放大笔刷 |
| 鼠标左键拖动 | 涂抹 |
| `z` | 撤销上一笔 |
| `s` | 保存当前掩膜 |
| `a` / `d` | 上一张 / 下一张（自动保存） |
| `q` | 退出 |

也可以用 [LabelMe](https://github.com/wkentaro/labelme/) 画多边形，再转成类别掩膜：

```powershell
python scripts/labelme_to_masks.py --json data\labelme_json --masks data\real_masks
```

## 4. 微调模型

```powershell
python scripts/finetune_segmentation.py `
  --images data\real_photos `
  --masks  data\real_masks `
  --epochs 20
```

- 默认从 `models/segmentation.pt` 继续训练，最佳权重写回同一路径。
- 数据少于 40 张时用 `--epochs 10~15`，防止过拟合；脚本已带翻转、亮度、旋转增强。
- 终端会打印每轮验证 mIoU 和各类 IoU；`models/segmentation_finetune_metrics.json` 留有记录。
- ONNX 导出失败不影响使用：运行时会自动优先使用更新时间更晚的 `.pt`。

## 5. 启用与验收

```powershell
# 重启 API 后检查
curl "http://127.0.0.1:8001/api/v1/health"
```

`segmentation.backend` 应显示 `torch`（微调后）或 `onnx`。

再跑一次照片对比任务，检查：

- `atlas.png` 里冲沟/坍塌/防护/对照的位置是否与实际坡面一致；
- `fusion.json` 的 `semantic.source` 是否为 `model`、分类覆盖率是否 >60%；
- 验证集指标：**mIoU ≥ 0.75**，冲沟和坍塌的 IoU 各 ≥ 0.5。

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 全图只预测一类 | 掩膜不是 0–4 的类别 ID（例如被存成 0/255 二值） | 用 `annotate.py` 重新保存，或检查 PNG 像素值 |
| 阴影被判成冲沟 | 训练集缺少阴影样本 | 补 10–20 张带阴影的照片，阴影标 0 或 255 |
| 防护垫识别差 | 颜色/材质与训练数据差异大 | 补防护类样本，至少 20 张 |
| 掩膜与照片对不上 | 文件名不同名或尺寸不一致 | 掩膜必须与照片同名 `.png`、同尺寸 |
| 微调后没生效 | 服务未重启，或 ONNX 文件更新时间更晚 | 重启服务；确认 health 的 backend 为 `torch` |

## 7. 时间预算（参考）

- 预标注：200 张约 2–3 分钟；
- 人工修正：熟练后 20–40 秒/张，200 张约 1.5–2 小时；
- 微调：20 epochs、200 张，GPU 约 5–10 分钟；
- 验收：跑 1–2 个任务即可。
