# 坡镜智安 · 演示设计与执行手册

> 目标：5 分钟让评委记住三件事——**便宜、快、能解释**。
> 版本：v1.0 · 2026-11-28 · 配套代码 `scripts/run_demo.py`

## 一、演示定位

**一句话**：拍两组照片，几分钟后拿到这场降雨冲走多少土、冲在哪里、属于哪类地貌的报告。

三个记忆点，全程反复回扣：

1. **便宜**：手机或普通相机就能拍，不需要全站仪、不需要专业测绘；
2. **快**：上传到出报告几分钟，现场可演示；
3. **能解释**：不只给一个体积数字，还给三维坡面、冲淤图和语义图谱。

## 二、受众与版本

| 版本 | 时长 | 适用场景 | 重点 |
|---|---|---|---|
| 电梯版 | 60 秒 | 展台路过、评委赶场 | 一句话 + 一张冲淤图 |
| 标准版 | 5 分钟 | 校赛现场答辩 | 完整链路 + 手机参与 |
| 深度版 | 12–15 分钟 | 技术评审、指导老师 | 架构、指标、局限、路线 |

| 0:30–1:00 | 两张照片 / 拍摄示意 | “雨前雨后各拍一组，固定路线、重叠 70%、画面里放一把标尺。” | 说明采集门槛低 |

| 3:30–4:10 | 语义图谱 + 下载 PDF | “不仅知道变了多少，还知道变在哪类地貌：冲沟、坍塌、防护区分别统计。” | atlas + PDF 打开 |

## 五、故障兜底（按发生概率排序）

| 故障 | 现象 | 处理 |
|---|---|---|
| GPU 被占/显存不足 | 进度停在“重建”很久 | 系统会自动回退 CPU（3–5 分钟）；直接切到预生成结果 |
| 网络断/隧道失效 | 手机打不开 | 改用本机网页 + 录屏；提前备好热点 |
| 上传超时 | 页面报“连接中断” | 换小一点的 ZIP（8 张），或用「合成样例」3 秒出结果 |
| 依赖/权重异常 | health 里 available=false | 播放 60 秒录屏 + 展示 `docs/demo/photo/` 的 PDF 与图 |
| 投影故障 | 屏幕黑屏 | 打印的 PDF 与 A3 冲淤图顶上 |

**兜底原则**：先讲结论，再修系统；永远不要让评委盯着报错。

## 六、必答题（背下来）

| 问题 | 回答 |
|---|---|
| 精度多少？ | 几何链路在解析地形上体积误差约 −3%；端到端受重建分辨率限制，1 m 距离下 5–10 cm 细沟会低估，真实数据需按标尺复核。 |
| 和全站仪/TLS 比？ | 不比绝对精度，比**频次与覆盖**：TLS 一次几千元、几小时；我们一部手机、几分钟，适合高频普查，发现异常再用高精度手段复核。 |
| 尺度怎么定？ | 画面放已知长度标尺/ArUco，当前手工填 mm/单位，下一步做自动解算（`survey.py` 已有控制点基础）。 |
| 语义标签哪来？ | 三条腿：几何规则自监督（冲沟/坍塌）、公开 CC-BY 数据（预训练）、人工修正 100–200 张（补防护/对照）。 |
| 为什么用 VGGT？ | 免相机标定、免 SfM 初始化，普通手机照片直接前馈出位姿与点图；代价是尺度任意，需要外部标定。 |
| 能商用吗？ | 代码链路可以；VGGT 需换 Commercial 权重，公开数据 CC-BY 需署名。 |

## 七、一键演示命令

```powershell
cd D:\tzzcup

# 1) 离线版：2 秒出全套结果（不需要 GPU、不需要网络）
python scripts/run_demo.py --mode quick

# 2) 真实链路版：用合成双时相照片跑完整 VGGT 流程（需权重，GPU 约 1 分钟）
python scripts/run_demo.py --mode photo --scene data/samples/synthetic_sem --max-views 4

# 3) 启动网页（本机）
uvicorn api:app --host 127.0.0.1 --port 8001
streamlit run app.py

# 4) 启动带令牌的远程入口（配合 Cloudflare 隧道）
$env:SLOPEWATCH_API_TOKEN="<32 位以上令牌>"
uvicorn public_api:app --host 127.0.0.1 --port 8011
```

产物默认在 `demo_output/quick/` 或 `demo_output/photo/`：`report.pdf`、`surface.png`、`dod.png`、`atlas.png`、`metrics.json`。
